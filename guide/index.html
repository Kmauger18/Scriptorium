Guide de l’atelier

Tout ce qu’il faut pour écrire un roman SMS dans Scriptorium, à la main ou en collant un script.

DémarrerSyntaxe des scriptsRèglesÉcrire avec une IASauvegardePublier

Démarrer

  1. Ouvrez l’atelier et choisissez Nouveau livre → Roman SMS.
  2. Dans l’onglet Persos, créez vos personnages. Le bouton D / G choisit le côté des bulles : à droite, le propriétaire du téléphone ; à gauche, ses contacts.
  3. Écrivez bulle par bulle dans la zone du bas, ou passez par ＋ → Coller un script pour ajouter un chapitre entier d’un coup.
  4. Vérifiez le rendu dans Lecture (les messages arrivent un à un) et dans Livre (pages réelles).

Règles à respecter

  1. Le prénom avant les deux-points est le vrai prénom du personnage, identique partout (24 caractères au plus : lettres, espaces, tirets, apostrophes, points). Un nouveau prénom crée un nouveau personnage.
  2. Le nom de contact affiché dans un téléphone se règle seulement sur la ligne ===, entre parenthèses. Une reprise sans parenthèses garde le dernier nom affiché.
  3. Une ligne sans préfixe se colle au message précédent. Elle ne doit donc pas commencer par *, !, [, >, # ou //.
  4. Évitez un mot isolé suivi de deux-points en début de ligne (Attention: …) : il serait pris pour un personnage.
  5. Chaque conversation commence sur une nouvelle page du livre imprimé.
  6. Une photo ou une capture s’affiche dans un cadre avec sa description. Dans l’atelier, cliquez dessus pour la remplacer par la vraie image.
  7. Les réactions (❤️) et les heures sous les bulles s’ajoutent ensuite dans l’atelier, en survolant une bulle.

Écrire avec une IA

Le prompt « roman SMS » contient toute la syntaxe, les règles de style et une liste de vérification. Remplissez la section « Mon projet » en bas, puis collez-le dans votre IA : elle vous propose un plan, puis écrit le script chapitre par chapitre, prêt à coller dans l’atelier.

Sauvegarde

Vos livres sont enregistrés automatiquement dans le navigateur de cet appareil, et un point de restauration est créé toutes les quatre minutes (Fichier → Historique des versions). Si vous videz les données du navigateur, ils disparaissent : exportez régulièrement le livre en .json, c’est votre vraie sauvegarde. Le même fichier se réimporte sur un autre ordinateur.

Publier

Dans Livre, choisissez le format (poche 11 × 17 cm pour un roman SMS), le papier et les marges. Le panneau Amazon KDP calcule la marge de reliure selon le nombre de pages, l’épaisseur de la tranche et la taille de la couverture à plat, et fournit un gabarit de couverture en SVG. Le bouton Imprimer / PDF produit le fichier intérieur ; l’onglet Fichier exporte aussi l’EPUB, la vidéo MP4, la page web et le script texte.
